title: "Printable Documents"
---

The following printable materials are referenced throughout the curriculum. All files are in the Upstream folder.

- **Barcode list** — complete set of pre-set program barcodes; laminate and keep a set at every table
- **EdMat (colour)** — activity mat for races, sumo, and line-following; print at tabloid/A3 or tile two letter sheets; laminate
- **EdMat (B&W)** — black-and-white version of the EdMat for printing where colour is unavailable
- **EdBook1 activity book** — EdBlocks student activity sheets (Activities 1–23)
- **Card Coding cards** — physical programming cards for Card Coding Lessons 1–5; print, cut, and laminate one set per pair
