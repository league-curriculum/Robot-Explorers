## Which Barcodes to Have Ready Every Session

| Barcode | Use |
|--------|-----|
| Clap controlled driving | Ball game, races, session openers |
| Obstacle avoidance | Obstacle field games, sensor intro |
| Line tracking | Line-following activities, sensor demos |
| Bounce in borders | Arena challenges, sumo warmup |
| Sumo | Sumo tournaments |
| Remote control (IR) | Ball game alternative, free play |

All barcodes are in the Edison-Curriculum-Catalog.md upstream file.
