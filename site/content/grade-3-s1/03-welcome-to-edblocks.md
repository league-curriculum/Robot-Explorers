title: "Session 3 — Welcome to EdBlocks"
---

**Opening concept:** Block coding is writing instructions without typing words.

**Activity:**
- EdBlocks Activities 8–9: intro to EdBlocks environment, connect Edison to device, download first program
- Students run the example program — watch it work, then deliberately break it (delete a block) and see what happens
- Challenge: modify the example program to do something slightly different. Add a block. Remove one. Predict before running.

**Possible tech issues:** Have a troubleshooting sheet ready. USB connection is the most common issue.

**Materials:** Devices (Chrome/Edge), USB cables, EdBlocks student activity sheets 8–9
