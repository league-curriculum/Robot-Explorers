title: "Session 1 — Robot Warm-Up"
---

**Activity:**
- For returning students: ball game tournament, two rounds (immediate engagement)
- For new students: quick robot intro using barcode list — clap control and obstacle avoidance
- Whole group: obstacle avoidance challenge — who can build the trickiest obstacle field?
- Introduce Card Coding: "What if instead of a program already built in, you put the program together yourself?"

**Materials:** Complete barcode list, EdMat, ball game setup, Card Coding card set
