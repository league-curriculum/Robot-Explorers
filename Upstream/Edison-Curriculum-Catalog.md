**Edison Robot**

Curriculum Catalog

Resource collection for K--5 instructors • meetedison.com

**About This Collection**

This collection gathers every free teaching resource from meetedison.com into one organized folder structure. Documents are organized into two top-level sets: Barcodes and Curriculum. All resources are free, Creative Commons licensed, and can be adapted for your classroom.

The Edison V3 robot supports four programming approaches, from completely screen-free card coding for the youngest students through Python for advanced learners. This catalog focuses on resources appropriate for K--5 (elementary) students.

+-------------------------------------------------------------------------------------+
| **SECTION 1: BARCODES**                                                             |
|                                                                                     |
| Physical programming cards and activity mats --- suitable for all K--5 grade levels |
+-------------------------------------------------------------------------------------+

Edison robots come pre-loaded with programs that activate when the robot scans a barcode. To scan: place Edison facing the barcode, press the round button three times, and Edison drives forward to read it. No computer required.

Pre-set programs include: clap-controlled driving, obstacle avoidance, torch following, line tracking, bounce in borders, and sumo wrestling. All of these are highly engaging for young students and require zero coding experience.

+-----------------------------------------------------------------+
| **Card Coding --- Screen-Free Programming**                     |
|                                                                 |
| Recommended for Grades K--4 • No computer required              |
+-----------------------------------------------------------------+

Card Coding uses physical barcode cards that students lay out on a table, then scan into Edison one by one. Students program the robot without touching a screen, making it the most accessible entry point for the youngest learners and classrooms with limited device access.

The format is highly collaborative: small groups physically arrange and debate card placement before running the program, generating natural discussion about sequencing and logic.

+-----------------------------------------------------------------+
| **EdBlocks --- Block-Based Coding**                             |
|                                                                 |
| Recommended for Grades 2--5 • edblocksapp.com                   |
+-----------------------------------------------------------------+

EdBlocks is a fully graphical, drag-and-drop robot programming language designed for ages 7--10. Students build programs by connecting icon-based blocks. No text entry required. The app runs in Chrome, Edge, or Opera on computers and tablets.

The curriculum has two phases: Activities 1--7 use pre-set barcode programs (no computer needed), and Activities 8--23 use the EdBlocks app. This means EdBlocks works even if computer time is limited, and it bridges naturally from Card Coding and barcode activities.

| **EdScratch --- Scratch-Based Coding**                          |
|                                                                 |
| Grades 4--5 (Advanced Only) • edscratchapp.com                  |
+-----------------------------------------------------------------+

EdScratch is based on MIT Scratch and is designed for students aged 10+. It introduces computer science fundamentals including loops, conditionals, variables, functions, and algorithms in a Scratch-like drag-and-drop environment.

This curriculum is not generally appropriate for K--5 students. However, advanced 4th--5th graders who have completed EdBlocks may be ready for Units 1--2.

| Suggested sequence and approach for elementary classrooms       |

**Suggested Learning Path by Grade Band**

**Grades K--2 (Ages 5--8)**

- Start with the Barcode Activity Book (EdBook1) --- 2--3 sessions. No experience needed.

- Use the EdMat for open exploration with pre-set barcode programs.

- Move to Card Coding Lessons 1--3 for screen-free introduction to programming concepts.

- Optional: "What is a robot anyway?" as an engaging first-day intro lesson.

**Grades 3--4 (Ages 8--10)**

- Start with barcodes (EdBook1 + EdMat) if students are new to Edison --- 1--2 sessions.

- Complete the full Card Coding curriculum (5 lessons) to build programming fundamentals.

- Move to EdBlocks Activities 1--7 (barcode phase), then 8--15 (app coding phase).

- Optional: "Operation: Neko Prime" as a culminating collaborative project.

**Grade 5 (Ages 10--11)**

- Complete EdBlocks Activities 1--23 as the core curriculum.

- Advanced students can begin EdScratch Units 1--2 after finishing EdBlocks.

- "Quad Squad robots" works well as a cross-curricular math tie-in for grade 5 geometry.

- "Operation: Neko Prime" makes an excellent culminating activity or STEAM week project.

**Key Teaching Notes**

- EdBlocks requires a computer (Chrome, Edge, or Opera) or tablet with USB. Confirm tech setup before the first coding session.

- Card Coding and barcodes need no computers --- ideal for when technology is unavailable.

- Print the EdMat at A3/tabloid or tile over two letter sheets. Laminate for durability.

- Keep printed copies of Edison-complete-barcode-list.pdf at every table --- students will need it constantly.

- The EdCreate builds require the expansion kit. Confirm V3 compatibility before purchasing.

- EdPy (Python) is included in this collection but is not recommended for K--5 students.

**Quick-Start Checklist for First Session**

- Charge all Edison robots (4--5 hours each)

- Print one EdBook1 barcode activity book per student or pair

- Print one EdMat per table group and laminate if possible

- Test barcode scanning: avoid glossy paper and direct sunlight

- Optional: run a drive calibration on robots that seem to drift (calibration barcodes in the barcodes folder)
